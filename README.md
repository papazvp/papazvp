# Independent Solana Searcher Developer

I develop and research Solana searcher infrastructure, focusing on cross-DEX arbitrage, transaction execution, and the analysis of on-chain outcomes.

## Areas of work

- Cross-DEX arbitrage research and route analysis
- Transaction simulation, execution diagnostics, and reliability
- Jito bundle submission and execution analysis
- Compute unit usage and transaction performance
- Research into ordered-bundle backrun execution

I focus on understanding the full execution process—from evaluating opportunities and simulation results to examining finalized transaction outcomes and costs.

## Public example

[Solana Execution Cost Example](https://github.com/papazvp/solana-execution-costs) is a small Rust project that demonstrates an offline calculation of hypothetical transaction costs using integer lamports.

My trading infrastructure and proprietary strategies are maintained privately.
